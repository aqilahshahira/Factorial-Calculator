# Factorial-Calculator

A straightforward and efficient program to calculate the factorial of a given non-negative integer.

## Description

The Factorial Calculator takes an integer input ($n$) from the user and computes its factorial using the standard mathematical formula $n! = n \times (n-1) \times (n-2) \times \dots \times 1$. It includes basic error handling for mathematical edge cases, such as establishing that $0! = 1$ and rejecting negative inputs.

## Features

* **Accurate Calculations:** Quickly computes factorials for non-negative integers.
* **Edge-case Handling:** Properly handles $0$ and invalid inputs.
* **Lightweight:** Fast execution with minimal dependencies.
